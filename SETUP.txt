IMPORTANT: This version preserves the original event list even before the online database is configured.

To make editing private to you but visible to everyone:

1. Create a free Supabase project at supabase.com.
2. Your admin email is already set to gracieisbell@gmail.com in schema.sql and config.js.
3. Run schema.sql in Supabase -> SQL Editor.
4. In Supabase -> Authentication -> Users, create your account with that same email and a password.
5. Run seed_events.sql ONCE in SQL Editor. This puts every original calendar event into the shared database.
6. In Supabase Project Settings -> API, copy your Project URL and anon/public key.
7. Open config.js and replace:
   YOUR_SUPABASE_URL
   YOUR_SUPABASE_ANON_KEY
   YOUR_ADMIN_EMAIL
8. Upload index.html and config.js to the same GitHub/Vercel project.

Result:
- Anyone can view the calendar.
- Only your authenticated email can add/delete shared events.
- When you add an event in Admin Login, everyone sees it after refreshing.
- Row Level Security prevents other visitors from editing, even if they inspect the website code.
- The original events are bundled into index.html, so a database/setup problem will no longer erase the calendar.
